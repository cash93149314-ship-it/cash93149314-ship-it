## 🚀 如何預覽與使用

### 方法 1：直接開啟
直接在檔案總管中雙擊 `index.html`，即可使用任意主流瀏覽器（Google Chrome、Edge、Safari 等）開啟查看。

### 方法 2：使用本地伺服器（推薦）
如果你有安裝 Python 或 Node.js，可以在本目錄執行：

- **Python**:
  ```bash
  python -m http.server 8080
  ```
  接著在瀏覽器打開：`http://localhost:8080`

- **Node.js (npx serve)**:
  ```bash
  npx serve .
  ```
